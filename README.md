# Simple JavaScript To‑Do List App

A minimal and functional To‑Do List web application built with plain
HTML, CSS, and JavaScript.\
Easily add, edit, and delete tasks through a clean interface.

##  Features

-   Add new tasks via input form
-   Edit existing tasks with an Update mechanism
-   Simple Delete functionality
-   Consistent alignment of action buttons using flexbox
-   Responsive design with modern UI styles

## 🛠 Technology Stack

-   *HTML5* for structure\
-   *CSS3* for layout and styling\
-   *Vanilla JavaScript* for core logic (add, edit, delete)

## 📂 File Structure

    ├── index.html        # Main layout & structure
    ├── styles.css        # Styling (container, buttons, list alignment)
    └── index.js          # JavaScript logic (todo array, add/edit/delete functions)

## 📖 Usage

1.  Clone or download the repository.\
2.  Open index.html in your browser.\
3.  Type your task in the input field and click *Add*.\
4.  To modify a task, click *Edit*, update the text, and click
    *Update*.\
5.  Remove a task by clicking the *Delete* (trash icon) button.
